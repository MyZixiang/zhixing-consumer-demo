# 知行 · 个人消费管理

[打开知行](https://my335.cn/zhixing-consumer-demo/)


暖白与森林绿界面的个人消费管理应用，支持账号登录、云端账本、关联退款、可复用预算方案、订阅管理、消费决策与 DeepSeek 消费助手。

此仓库存放可直接部署到 GitHub Pages 的静态网页。首页为 index.html，脚本、样式与图标已内嵌。

每个新账号从空账本开始，账号认证与数据库由 Firebase 提供。账目按账号保存并通过数据库权限隔离，不写入 GitHub 仓库。外币采用手动汇率；记账不会发起支付，也不会取消服务方的订阅。

消费助手按需分析已录入消费，并把自然语言整理为可编辑的人民币记账草稿；只有用户确认后才写入账本。模型调用通过 Cloudflare Worker 核验登录凭证，DeepSeek API Key 保存在 Worker Secret 中，不包含在此静态仓库里。

消费决策卡保存购买前的目的、预期价格和使用频率；购买后关联真实支出，记录使用次数、满意度及原因。Agent 可以按需参考这些反馈，为下一次购买提供有依据的建议。复盘和可支配额由用户确认填写，不自动观察物品使用、不推断银行余额。决策卡与账本一同按账号保存，并纳入 JSON 备份。

GitHub Pages 配置：从 main 分支的根目录发布。
