# 知行 · 个人消费管理

[打开知行](https://my335.cn/zhixing-consumer-demo/)


[进入知行新版](https://zhixing-consumer-d4e7ao9abd8dcf4-1528175210.tcloudbaseapp.com/) · [打开旧版，导出账本](./legacy-firebase.html)

记下收支、安排预算、管理订阅，并记录购买前的期待和使用后的真实反馈。新版使用邮箱验证码登录，新用户从空账本开始。

旧用户可在旧版「账号与数据」导出 JSON 备份，再登录新版核对并确认导入。同邮箱不会自动合并旧账本；旧版仍需能够连接原账号服务的网络。

本仓库首页 index.html 是新版入口页，不承载新版登录应用。新版应用单独托管；legacy-firebase.html 保留迁移前的旧版页面。账目、验证码、访问令牌和模型密钥不写入本仓库。

GitHub Pages 配置：从 main 分支的根目录发布。
