# 知行 · 个人消费管理

[打开知行](https://my335.cn/zhixing-consumer-demo/)


暖白与森林绿界面的个人消费管理应用，支持账号登录、云端账本、关联退款、可复用预算方案和订阅管理。

此仓库存放可直接部署到 GitHub Pages 的静态网页。首页为 index.html，脚本、样式与图标已内嵌。

每个新账号从空账本开始，账号认证与数据库由 Firebase 提供。账目按账号保存并通过数据库权限隔离，不写入 GitHub 仓库。外币采用手动汇率；记账不会发起支付，也不会取消服务方的订阅。

GitHub Pages 配置：从 main 分支的根目录发布。
